# Project Agent Guidance

## Web of Science

- For Web of Science work, read [sites/webofscience/AGENTS.md](sites/webofscience/AGENTS.md) first.
- Use `$wos-document-search` for Smart Search, document fielded search, Query Builder, cited-reference search, result refinement, analysis, and same-site record lookup; use `$wos-researcher-search` for author lookup and `$wos-researcher-profile` for authenticated profile, metrics, records, or settings work.
- Keep Web of Science work in the Codex in-app browser and preserve the user's existing tab and session. Do not record passwords, cookies, email addresses, ResearcherIDs, live counts, or one-off search results in durable guidance.

Other site-specific instructions live under `sites/<site>/AGENTS.md` and should be read only for that site's work.
