# 曼報 Pro（Firstory）網站操作指引

這份指引適用於透過 Codex 內建瀏覽器操作 `https://pro.manny-li.com/`。它整理目前已驗證的公開與登入後導覽、內容列表、方案 FAQ、帳戶入口與會員內容存取邊界；文章、集數、日期、數量、價格和會員狀態都必須在當次任務重新取得。

## Global routing

- 想找文章、依內容產品瀏覽，或查看文章列表 → `$manny-pro-content`，從 `/posts` 或頁首的內容標籤進入。
- 想找 Podcast 集數、播放時間或收聽平台 → `$manny-pro-content`，從 `/episodes` 進入。
- 想了解方案、權益、付款、退款、取消或七日鑑賞期 → `$manny-pro-content`，從 `/join#faq` 開啟對應 FAQ；付款、取消、退款等實際帳務動作不在探索範圍內。
- 需要會員限定文章／集數 → 先確認使用者明確要求讀取受保護內容，並只使用同一個 Codex 內建瀏覽器分頁中既有的手動登入狀態；不可代填密碼、OTP、信用卡或其他敏感資料。
- 目前頁面若明確顯示帳戶入口，視為已登入網站變體；可直接重新核對公開頁與安全的會員內容讀取流程，不需要另問一次是否登入，但仍不可執行帳務或帳戶變更。

## Navigation

- 首頁：`/`；價值主張、內容產品說明、會員權益、公開 Podcast 收聽平台、精選單集與文章入口。
- 方案：`/join`；方案說明、研究團隊、研究倫理、價格與 `/join#faq` FAQ。
- Podcast 列表：`/episodes`；有「一般」與「會員限定」分類、排序切換，以及通往 `/episodes/<episode-slug>` 的集數頁。
- 文章列表：`/posts`；有「一般」與「會員限定」分類、排序切換、文章卡片、`閱讀更多` 與 `載入更多文章`。
- Podcast 詳情：`/episodes/<episode-slug>`；登入後可見集數標題、`敘述`、留言區與自訂播放器的跳轉／速度控制；不要因為沒有原生 `<audio>` 元素就判定沒有播放器。
- 文章詳情：`/posts/<post-slug>`；登入後可見文章正文的 heading 階層、外部／內部引用與 `延伸閱讀`；從列表卡片進入，不要猜 slug。
- 內容標籤：頁首以可見名稱連到 `/posts?tag=<tag-id>`，目前已驗證的名稱是「商業解碼」、「科技曼讀」、「巨人之聲」與「曼報俱樂部」。優先點擊目前 UI 的可見連結，不要猜測 tag id。
- 帳戶管理：帳戶選單的 `會員管理` 導向 `/account/profile`；可讀取 `帳戶資訊`、`已連結的應用程式`、`付款資訊` 等區塊，但 `更改付款資訊` 與 `登出` 都不是探索互動。
- 頁尾：Firstory 的探索、關於、創作者登入、服務條款、隱私政策與幫助中心；只有在任務需要時才離開曼報 Pro 網域。

## Operating rules

- 只使用 Codex 內建瀏覽器；不要改用 Chrome、外部瀏覽器、API、爬蟲、CLI、cookies、local storage 或 session 檔案。
- 先讀取目前分頁與可見 UI，再決定路由。保留使用者原有分頁與登入狀態，不要為了探索而登出或重新登入。
- 公開探索可做讀取與可逆互動：切換內容分類、排序、FAQ 展開與載入更多。不要按下付款、訂閱、取消、退款、登出、外部 OAuth 授權或其他會改變帳務／帳戶狀態的操作。
- 頁面上的帳戶名稱只代表 UI 顯示了帳戶入口，不代表該帳戶一定有某項內容權限；以頁面實際顯示的卡片、播放按鈕、會員標記或登入提示驗證。
- 會員限定內容、會員管理、Apple Podcasts／Spotify 綁定與專屬 RSS 屬受保護分支。已登入時可做會員內容與帳戶頁的讀取核對；若未登入且使用者沒有明確要求，不要深入讀取，出現登入牆時請使用者在同一個內建瀏覽器分頁手動登入後再繼續。
- 專屬 RSS 連結等同會員憑證，絕不可複製到回覆、檔案、日誌或第三方服務。

## Validation and freshness

- 每次內容查詢都重新開啟列表或使用目前 UI 的刷新／載入控制；不要把當前文章數、集數數量、日期、價格、排名或排序結果寫入長期指引。
- 互動後至少核對兩項：主要 heading、目前 active/selected 分類、排序按鈕文字、URL/query state、第一個結果標題或載入後出現的結果卡片。
- 排序按鈕目前以「最新到最舊」／「最舊到最新」呈現，點擊後會重新載入列表；等待內容出現後，再以首批卡片與按鈕文字確認結果。
- 會員內容若看不到播放按鈕或文章正文，不要猜測是內容不存在；先檢查目前登入帳號是否為付款帳號，必要時請使用者手動處理登入。
- 標籤頁要分開核對 tab 狀態與卡片的 `會員限定` 標記；目前登入變體曾觀察到「一般」tab selected 但卡片仍為會員內容，不能只依 selected tab 判斷存取類型。
- 探索 Sitemap 或 `robots.txt` 時，`ERR_BLOCKED_BY_CLIENT`、goto timeout、空白自動化回應或 parser 沒有 body 都只代表瀏覽器控制層尚未取得內容；先視覺檢查並以正常瀏覽器導覽重試。只有實際取得 HTML、空白內容或格式錯誤時才標記 `invalid`；重試後仍無 body 要標記 `client-blocked`，不可寫成 Sitemap 不存在或沒有內容。

## Authenticated recheck

- 登入後重新核對 `/`、`/join`、`/episodes`、`/posts` 與四個內容標籤頁；不要把公開變體的結果直接套用到登入變體。
- `/episodes` 的 `會員限定` tab 在目前 session 可顯示集數卡片；進入集數詳情後以標題、`敘述`、跳轉／速度控制與留言區驗證，不要按 `撰寫留言` 送出內容。
- `/posts` 的 `會員限定` tab 在目前 session 可顯示文章卡片；`載入更多文章` 是可逆的讀取互動，必須確認新卡片真的出現。
- `/account/profile` 只讀取區塊名稱與可見功能；不要點擊 `更改付款資訊`、`登出` 或任何付款／授權控制。

## Drift maintenance

- 操作前先將目前可見的路由、標籤、控制項、權限與第一方說明和本文件及 `$manny-pro-content` 比對。
- 若穩定的 UI、路由、頁型或工作流程改變，以目前 UI 和 Firstory 官方說明為準完成安全任務，並在授權工作區更新負責的文件。
- 更新時記錄公開／受保護變體、頁型、舊行為、目前行為與驗證方式；不要寫入密碼、cookies、tokens、帳戶識別資料或動態內容值。
- 修改後重新執行受影響的安全流程與 skill validator。若差異廣泛、矛盾或無法安全驗證，標記 maintenance gap，不要猜測。
