# 全國法規資料庫（law.moj.gov.tw）

本目錄描述已用 Codex 內建瀏覽器探索過的「全國法規資料庫」。凡任務涉及 `https://law.moj.gov.tw/` 的法規、司法解釋、條約協定、兩岸協議、最新訊息、跨機關或智慧查找，先讀本檔，再依意圖載入對應 skill 與 references。

## 執行邊界

- 以 Codex 內建瀏覽器的目前分頁為唯一操作介面；同一探索任務只操作目前分頁，不建立或切換分頁。
- 每次導覽後確認目前 URL、頁面標題或主要 heading，並取得同一分頁的截圖與 DOM；若截圖工具失敗，明確標記為「DOM 已驗證、視覺重試失敗」，不要把它當成完整視覺證據。
- UI 是本網站操作真相。官方 OpenAPI 文件可用來理解入口，但本套件未以直接 HTTP/API 呼叫取代瀏覽器驗證；除非使用者明確改變邊界，不要繞過瀏覽器。
- 預設只讀。不要登入、輸入憑證、儲存我的最愛、訂閱電子報、寄送回饋或送出任何對外表單；需要這些動作時先停下來請使用者確認。
- 會員登入目前只驗證到登入入口與未登入狀態。不要猜測或要求使用者提供密碼；若任務需要私人收藏或資料夾，先完成公開探索，再請使用者自行決定是否接手登入。

## 穩定的站點規則

- 首頁全域查詢與「綜合查詢」不是同一個表單；先依使用者是否指定資料類別決定入口。綜合查詢可選中央法規、條約協定、兩岸協議與司法類別，並可在法規名稱／法條內容間切換。
- 中央法規的法規識別核心是 `pcode`；全文、編章節、單一條文、條號檢索、條文檢索與沿革都由同一 `pcode` 延伸。不要只用顯示名稱作為唯一識別。
- 條號查詢支援逗號分隔的條號、連字號範圍與點號之條，例如 `1,11-13,35,756.1`；送出後必須以結果 URL、heading 與實際條文確認語法成功。
- 所有清單的筆數、頁數、熱門案例、搜尋結果與最後更新日期都可能變動；不要把本輪看到的數字寫入回答、測試或 skill。
- `最新訊息` 顯示最近一年；官方更新說明顯示最新訊息每日更新，中央法規、司法解釋、條約協定、兩岸協議、綜合查詢與電子報按週更新。跨機關資料則是機關網站的週期性擷取，應保留來源與擷取語境。
- 網站聲明不是法律意見。若資料庫文字與主管機關正式公布文字不一致，以主管機關公布文字為準；回答法律問題時提供查證路徑，不要把資料庫內容包裝成個案法律建議。
- 英文版位於 `/Eng/index.aspx`；中英文不一致時以中文版本為準。
