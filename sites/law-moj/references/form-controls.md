# Form controls and safe workflows

所有表單都在同一個 Codex 內建瀏覽器分頁操作。每次送出後確認 URL、頁面 heading、已選條件與結果內容；不要只依賴按鈕點擊沒有報錯。

## 全域與綜合查詢

- 首頁的「整合查詢」是全域入口，欄位 placeholder 為「整合查詢」，提交後會進入全域結果路由；若使用者指定類別或需要日期／文號，改用 `/Law/LawSearchAll.aspx`。
- 綜合查詢可選：中央法規、條約協定、兩岸協議、憲法法庭裁判（新制）、大法官解釋（舊制）、最高法院民事判例、最高法院刑事判例、最高行政法院判例。
- 關鍵字欄位為「含有」「且含」「或」「不含」；可選法規名稱、法條內容，並選擇現行或已廢止法規。日期以民國 3+2+2 碼輸入，發文文號是另一個條件。
- 官方表單提示一次選擇一種條件類型；若條件組合不清楚，先縮小到一個資料類別和一個關鍵字，再逐步增加條件。

## 中央法規與法規詳情

1. 開啟 `/Law/LawSearchLaw.aspx`，依左側分類或現有清單找法規。
2. 若要排序，使用「變更排序」後送出，並確認 URL／選項與清單順序已變更。
3. 從實際法規連結取得 `pcode`，再進入全文頁。
4. 依需求選「所有條文」「編章節」「條號查詢」「條文檢索」「沿革」；需對外分享時優先使用頁面的友善列印或 PDF 入口，但不要在未確認下載結果前聲稱檔案已建立。

條號查詢：在 `BTNType=NO` 頁面輸入條號。逗號分隔個別條號，`-` 表示範圍，`.` 表示之條；例如 `1,11-13,35,756.1`。送出後應看到 `LawSearchContent.aspx`，並逐一核對結果條號。

條文檢索：在 `BTNType=CON` 頁面填「含有」或其他條件；官方 UI 要求「含有」欄位，其他欄位代表且含／或／不含。結果頁要檢查關鍵字高亮與條文上下文，避免把摘要當全文。

## 最新訊息

- `/News/NewsList.aspx` 支援全部、法律、法規命令、行政規則、地方法規、法規草案；分類與分頁是 URL query 的一部分。
- 表格欄位是日期、類別、摘要；每列可進入 `NewsDetail.aspx?msgid=<ID>`。
- 每頁筆數可在 UI 選 20、40、60；不要記錄固定總筆數。以頁面標示的「最近一年」作為時間範圍。

## 跨機關檢索

- `/CrossGov/CrossGov.aspx` 的「含有」關鍵字為必要條件，且至少要選一個中央或地方機關範圍。
- 可加入「且含」「或」「不含」，再勾選機關（例如法務部）。安全驗證可用公開、低風險的短詞，送出後確認結果頁的機關、命中內容與「庫存頁面」連結。
- 結果是機關網站的週期性擷取；不要把擷取頁面當成主管機關最新正式文本，也不要遞迴打開未授權的外部網站。

## 司法、條約與兩岸

- 司法入口先用分類與日期排序，從清單取得完整司法識別參數，再開單筆。司法單筆可能提供司法院外部連結；外部連結只在使用者明確要求且安全邊界允許時開啟。
- 條約協定可按地區與名稱／日期排序；網站主要提供中文／英文版本，其他語言依官方說明轉向外交部資料。
- 兩岸協議清單可排序、分頁，部分項目會提示有附件；先在全文頁確認附件與版本。

## 不可自動化的分支

- 不登入、不輸入帳密、不操作會員最愛／資料夾。
- 不送出回饋、電子報訂閱或任何會對外產生通知的表單。
- 不把 API 文件、搜尋摘要或智慧查找建議當成法律意見；完成查找後仍須提示官方文本優先與個案諮詢邊界。
