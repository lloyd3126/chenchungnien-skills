# First-party guidance and provenance

下列規則來自網站自己的首頁、服務說明、資料範圍、更新說明與 Q&A。它們是 Agent 判斷範圍與可信度的依據；頁面中的日期與數量仍需每次重新讀取。

## 官方範圍

- `/Service/Intro.aspx` 說明各功能區：最新訊息涵蓋最近一年異動；中央法規涵蓋憲法、法律、法規命令與組織法規；司法區含憲法法庭裁判（新制）、大法官解釋（舊制）及最高法院民刑事／最高行政法院判例；條約協定與兩岸協議各有專區；綜合查詢跨越上述類別；跨機關是對機關法規網站的週期性擷取。
- `/Service/LawData.aspx` 進一步定義搜尋範圍與術語，例如法律、命令、實質法規命令及第一／第二類行政規則。遇到分類爭議，優先回到該頁，不要自行創造分類。
- `/Qanda.aspx` 說明收錄內容、歷史法規／命令、條號語法、電子報、會員服務與資料更新；行政規則由主管機關維護，最新訊息可能連到公報或機關資料庫。

## 更新與時效

- `/Service/refresh.aspx` 的更新表顯示：最新訊息每日更新；中央法規、司法解釋、條約協定、兩岸協議、綜合查詢與電子報按週更新。
- 首頁與服務頁可能顯示資料截止日期；這些值會變動，回答時重新讀取並附帶「截至頁面顯示日期」的限定，不要把探索當天的日期寫死。
- 跨機關內容是由機關網站週期性擷取，結果中的機關／庫存頁面與擷取狀態應一併保留。

## 權威性與使用限制

- 首頁聲明本資料庫提供法規訊息與查詢服務，不提供法律意見；若資料庫內容與主管機關正式公布文字有差異，以主管機關公布文字為準。
- 英文首頁聲明中英文不一致時以中文版本為準。
- 智慧查找是情境導覽與資源索引，不是法規全文或法律結論；搜尋摘要的命中不等於適用於使用者個案。
- `/api/swagger/index.html` 是官方 Open API 文件入口。本專案只使用它辨識文件與資料入口，除非使用者明確授權，不用直接 API 請求繞過瀏覽器與當前分頁的驗證規則。

## 對外與會員服務

- `/Mem/Login.aspx` 導向 E 政府會員登入，會員可設定最愛法規與自訂資料夾；這些是受保護功能。
- `/RelatedWebsite.aspx` 與 `/Service/LegalAid.aspx` 主要是外部／工具網站目錄；需要外部網站內容時，先告知來源邊界，再依使用者要求進一步探索。
