## 重跑時的驗證順序

1. 讀 `sites/judicial-lawsearch/AGENTS.md` 與本 references。
2. 確認使用者目前分頁仍是預期的入口；不要擅自建立新分頁。
3. 開啟首頁與 `/sitemap.aspx`，記錄 URL、標題、heading、截圖與 DOM。
4. 依任務意圖只選一個子系統與一個查詢入口；先用頁面提供的低風險公開示例或使用者指定條件。
5. 查詢後確認結果 heading、側欄分類、iframe 內清單與分頁／排序狀態。
6. 只從目前結果頁取得一個可見詳細 href，閱讀 metadata 與正文開頭；不批量遍歷 ID。
7. 若要維護文件，只更新穩定路由、欄位、第一方說明與安全邊界；移除即時筆數、日期、查詢 token 與動態熱門項目。

## 證據分類

| 分類 | 意義 |
| --- | --- |
| UI-verified | 同一分頁已取得可讀 DOM，且截圖成功，或經重試取得視覺證據。 |
| client-blocked | 瀏覽器控制層阻擋請求；不能據此判定頁面沒有內容。 |
| error-page | 網站實際顯示錯誤頁；應記錄錯誤文案與重試結果，不改寫成正常內容。 |
| dynamic | 可見但會變動的清單、筆數、日期、瀏覽人次或結果正文；不固化到技能規則。 |
