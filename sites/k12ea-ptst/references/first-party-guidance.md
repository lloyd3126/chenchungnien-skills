# 第一方說明與解讀限制

這份 reference 只整理網站自己提供的定義與操作說明。它不是法律意見、隱私評估、薪資保證或登入後行為的推論；每次回答仍要開啟目前頁面核對。

## About page

`關於本專區` 自述本專區整合國中小的代理、代課、兼任及正式（獨招）甄選公告，提供教師與學校的互動式配對，並另設縣市教師攬才及支持措施公告區。這可用來解釋網站定位，但不能保證一定媒合成功或代表所有學校的招聘規則。

## Job-seeker instruction

`求職說明` 目前文字表示，使用者需在登入後進入教師登入的履歷表並完成履歷，才能查詢職缺；頁面同時提供求職流程圖。公開首頁與 `職缺資訊` 頁在本輪未登入 session 仍顯示部分／完整職缺列表，這是目前 UI 的另一個觀察。未來回答應將兩者分開表述：

- 「說明頁的要求」：登入並完成履歷後可查詢。
- 「目前公開 UI」：未登入可見職缺搜尋與列表，但可見範圍、聯絡資料與後續動作可能受限。

不要以其中一項覆寫另一項，也不要假設登入後一定會改變哪些欄位。

## FAQ qualification example

本輪展開的 FAQ「想成為代理老師，需要具備什麼資格？」引用網站所列聘任辦法第 3 條，文字按資格順序提到合格教師證書、修畢師資職前教育課程證明及大學以上畢業者等情形，並提到公開甄選、教師評審委員會與未滿三個月代課／代理的不同程序。這些是 FAQ 當下的網站說明；涉及個案、期限、主管機關核准或現行法規時，應重新讀取 FAQ 與站內法規表的第一方連結，不要自行下法律結論。

## Registration terms

按下 `快速註冊Sign` 會先開啟會員約定條款 modal。可見條款說明求職者服務包含履歷刊登、瀏覽職缺、應徵紀錄與多筆履歷管理；也說明履歷可能提供給求才學校使用。條款要求先向下捲動閱讀，再由使用者自行勾選同意。

註冊表可見 Email、密碼、姓名、手機、生日、身分證字號與驗證碼等欄位，且頁面顯示密碼強度規則。這些都是敏感資料與同意／傳輸邊界：Agent 不得代填、代收簡訊驗證碼、代解 CAPTCHA、代勾選或代按 `我同意`／`註冊`。
