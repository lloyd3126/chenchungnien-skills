# Tabelog 一方說明與限制

這些是網站自己提供、適合保留的穩定語義；需要精確或最新規則時仍應在內建瀏覽器重新開啟原頁。

## 口コミ的意義

食べログ的「店舗の口コミについて」說明：口コミ是使用者實際用餐時的主觀感想／意見，可能正面也可能負面；食べログ不對口コミ內容做正誤判斷，口コミ也不代表餐廳的絕對評價，只能作為參考。頁面也說明投稿會依口コミガイドライン由專任人員目視確認，違規內容可能被處理。

原頁：[店舗の口コミについて](https://tabelog.com/help/r_about_review/)

## 評分與排名

餐廳的「平均・分布」頁說明，頁面中的使用者平均／分布是簡單平均與簡單分布；餐廳顯示的點數則是食べログ自己的演算法計算，兩者不可直接當成同一個數值。排名、點數與樣本量會隨網站資料更新，使用時要重新取得。

## 投稿指南中對 Agent 的重要限制

口コミガイドライン要求投稿內容以實際用餐經驗為基礎並具體描述，且應選擇正確的利用種別（昼、夜、テイクアウト、デリバリー、その他）。試吃會、試營運或接待等非一般利用需標示「通常利用外口コミ」。指南也限制未經確認的斷言、個人攻擊、隱私／著作權侵害、法律或衛生指控、付費／宣傳目的投稿與商業宣傳。

因此網站探索 skill 不應自行發佈口コミ、照片或店家內容；即使使用者要求草擬，也要把網站提交視為另一個需要確認的動作。

原頁：[口コミガイドライン](https://tabelog.com/help/review_guide/)

## 新鮮度與查證

口コミ頁本身提醒內容可能是訪問當時的資訊，可能與最新狀態不同，使用者應向店家確認。營業時間、預算、付款方式、空席、予約可否、菜單與店家公告都要在當次任務重新查看，不能把本 reference 的探索樣本當成現況。

網站定位與公開功能入口：[食べログについて](https://tabelog.com/help/beginner/)
