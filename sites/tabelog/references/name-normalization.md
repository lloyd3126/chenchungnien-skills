# Tabelog 店名與品名正規化

## Purpose

Tabelog 的正式店名、分店名與品名通常以日文呈現，但使用者預設需要繁體中文回答。保留來源名稱有助於搜尋與核對，不能取代中文化的使用者介面。

## Candidate fields

每個候選項目都要在內部記錄以下欄位：

- `name_original`：目前頁面可見的正式原名，不能自行改寫。
- `name_zh`：繁體中文名稱、台灣常用譯名，或可辨識的品牌音譯。
- `name_display`：最終給使用者看的名稱。

`name_display` 必須在候選進入排名或輸出前完成。預設格式是：

`中文名稱（原文名稱）`

如果品牌本身使用拉丁字母，保留品牌並翻譯類別或分店，例如 `Échiré 奶油糕點西武池袋店`。如果日文是不可可靠直譯的專有名詞，使用台灣熟悉的音譯或保留品牌名，不要捏造字面意義。

## Source and output separation

- 搜尋、消歧與連結使用 `name_original`。
- 使用者可見的主要名稱使用 `name_zh` 或 `name_display`。
- Tabelog、官方網站與 SNS 連結承擔正式原名，不需要把日文原名當成主要店名重複輸出。
- 原文只可出現在括號、來源連結、精確搜尋詞或解釋名稱辨識差異的地方。

## Final language gate

輸出前逐一檢查所有店名與品名：

1. 已有 `name_zh` 或台灣熟悉的音譯。
2. 主要顯示名稱不是未翻譯的日文原名。
3. 原名只保留在括號、來源連結或必要的搜尋詞中。
4. 整段回答使用繁體中文。
5. 若無法可靠翻譯，保留品牌名並翻譯可確定的類別、品項或分店，不要直接把日文整串原樣輸出。

若任一候選未通過，先完成正規化再產生排名，不得以「來源就是日文」作為跳過理由。
